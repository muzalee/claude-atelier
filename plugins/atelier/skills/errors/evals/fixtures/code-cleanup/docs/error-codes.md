# Error codes

Quote the code shown on screen when you contact support.

| Code | What it means | What to do |
| ---- | ------------- | ---------- |
| A0001 | Email or password is wrong | Try again, or reset your password |
| A0004 | Your session expired | Sign in again |
| A0009 | Too many attempts | Wait a minute |
| P0001 | Card was declined | Try another payment method |
| V0002 | A required field is empty | Fill in the highlighted fields |
| R0404 | Not found | Check the link |
